# Посмотри в окно

**«Посмотри в окно»** — это интерактивное веб-приложение для виртуальных путешествий. Пользователь может выбрать город и время суток, чтобы увидеть атмосферное видео из этой точки мира. Проект создан для того, чтобы дать возможность мгновенно «перенестись» в другую страну и почувствовать её настроение.

## О проекте

Приложение представляет собой современный интерфейс для поиска и просмотра видеоконтента. Основной акцент сделан на удобстве фильтрации и визуальном отклике системы.

### Основной функционал:
- **Интеллектуальный поиск**: текстовый ввод названия города для фильтрации видео.
- **Фильтрация по времени суток**: выбор одного или нескольких вариантов (Утро, День, Ночь) с помощью кастомных чекбоксов.
- **Динамический список**: автоматическое обновление списка видео-карточек при изменении параметров поиска.
- **Интерактивный плеер**: мгновенное переключение видео при выборе карточки из списка.
- **Обработка состояний**:
    - Реализованы индивидуальные прелоадеры для области видео и области списка.
    - Реализован экран ошибки на случай, если видео по запросу не найдены.

### Технологический стек:
- **HTML5**: семантическая разметка, использование тегов `<template>` для оптимизации рендеринга списка.
- **CSS3**:
    - **Flexbox и Grid**: создание сложной адаптивной сетки.
    - **Продвинутые селекторы**: использование `:has()` для реализации зависимости стилей родителя от состояния дочерних элементов.
    - **Кастомизация**: полная переработка стандартных чекбоксов, создание кастомного скроллбара.
    - **Доступность (Accessibility)**: использование `:focus-visible` для поддержки навигации с клавиатуры.
- **JavaScript (Vanilla JS)**: работа с DOM, обработка событий, управление состоянием приложения и работа с данными.
